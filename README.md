## Google website verification

Website publication and Google website ownership verification are separate steps.
No Search Console verification token has been provided or installed yet.

1. The Play Console account owner adds the full public URL above as a **URL-prefix** property in Google Search Console.
2. Select **HTML tag**, then supply the generated `google-site-verification` meta tag to the website maintainer.
3. The maintainer adds the exact tag inside the `<head>` of `index.html`, commits and pushes to `master`, and verifies publication.
4. The owner completes verification in Search Console and sends the website verification request from Play Console.
5. Keep the verification tag deployed after verification. Do not invent a token or copy one from a different property/account.

Use the exact English registered name `DMC masterone 1413,1414` when entering the legal business name. This is separate from the service name, Magic Kidney.

Official guidance: https://support.google.com/googleplay/android-developer/answer/13205715
